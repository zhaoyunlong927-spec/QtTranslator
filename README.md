# Qt TS 自动翻译

跨平台桌面工具，使用 Python 3 和 Tkinter。运行：

```sh
python app.py
```

选择翻译服务并配置完整接口地址：OpenAI 兼容的 chat completions API、LibreTranslate 的 /translate，或本机 Ollama 的 /api/chat。Ollama 需要先安装、启动并下载所选模型；LibreTranslate 需要可访问的服务，部分服务要求 API 密钥。网络服务会接收待翻译的原文。

打开 TS 文件，设置目标语言后开始翻译，可双击修改译文，再另存为新文件。默认只翻译空译文和 unfinished 条目。复数（numerus）条目暂不自动翻译；消失和过时条目会显示，保存时保留。翻译结果应在 Qt Linguist 中复核，尤其是快捷键、富文本和上下文。

## 工作台功能

条目按 TS 的 `unfinished`、`vanished`、`obsolete` 标记和译文内容显示状态，可搜索上下文和文本、按状态筛选。默认跳过已完成、占位符异常、复数及过时条目；勾选重新翻译后也会处理已完成和占位符异常的普通条目。显示并检查 Qt 参数、HTML 标签及换行；自动翻译前会保护这些标记。未完成但已有译文的条目默认仍会重新翻译。

复数条目仅显示，不能在此编辑或自动翻译。保存采用 XML 重新序列化，原始文件的排版、DOCTYPE 和 XML 声明以外的处理指令可能变化，请另存并用 Qt Linguist 验证。自动译文仍需人工审核。

## 配置和百度翻译

语言和模型支持下拉选择或手动输入。选择“百度翻译”时，填写百度翻译开放平台的 APP ID 和密钥；常用 Qt 语言代码会转换为百度对应的代码。各服务的地址、密钥和模型分别保存；点击“保存配置”或正常关闭窗口时，程序会写入当前工作目录的 `qt_translator_config.json`，下次启动自动读取。**密钥以明文保存在该文件中**，请勿分享或提交到代码仓库。百度翻译需要开通对应服务，并遵守账户的调用频率与计费规则。

当翻译服务修改了占位符保护标记时，程序会尝试将文本分段翻译，再放回原始占位符。分段可能影响语序和翻译质量，请人工复核；如果仍无法安全保留占位符，会跳过该条继续处理其余条目。单条网络或服务错误会显示为翻译失败，批量任务继续处理其他条目；如配置有误，请停止任务并检查。

翻译设置中可以选择并发数，默认为 1；并发数不等于每秒请求数，具体速度仍受翻译服务限流和本机性能影响。翻译完成的条目会实时更新表格。暂停后不再启动新请求，停止后等待已发出的请求结束；完成后可以保存。单条失败会跳过，筛选“翻译失败”并选择条目可查看原因；下次启动翻译时可重试。若凭据或服务配置有误，请及时停止并修正。

双击普通条目可打开多行编辑器，支持单条自动翻译、检查标记和在光标处插入缺失标记；自动翻译替换已有编辑内容前会确认。标记不匹配时可以返回修改，或选择保存为待确认。编辑后还需在主窗口另存 TS 文件。

程序将 Qt 占位符、富文本标签、实体文本、换行及常见字面反斜杠转义作为标记保护；XML 实体在读取时会按 XML 规则解码，保存时由 XML 库重新转义，无需手动把 & 写成 &amp;。分段回退和机器翻译仍需人工审核，复杂富文本、快捷键及特殊 TS 结构不保证完全自动处理，请使用 Qt Linguist 检查。

工作台左侧按上下文分组，显示已完成/有效条目数；过时条目不计入有效总数，复数条目计入总数但目前不能在此确认。状态符号：✓ 已完成，○ 未翻译，? 待确认，! 异常或失败，≡ 复数，– 过时。工具栏支持上一条、下一条、上一/下一待处理、确认和确认并下一条；导航受当前分组、状态和搜索筛选限制。按 Ctrl+F 跳到搜索框，在搜索框中按 Esc 清空。确认译文需保证非空且标记匹配，修改后仍需另存 TS 文件。
